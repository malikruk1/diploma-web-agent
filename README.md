# Веб-агент для дипломної роботи

Дипломна робота: **«Застосування методів автоматизованого оцінювання агентів для виконання задач у веб-середовищі»**
(КНУ імені Тараса Шевченка, факультет радіофізики, електроніки та комп'ютерних систем).

Пошуковий веб-агент, який відповідає **лише** на питання про факультет (ФРЕКС), використовуючи сайт [rex.knu.ua](https://rex.knu.ua).
На сторонні питання агент ввічливо відмовляє. Агент — об'єкт тестування для системи автоматизованого оцінювання.

## Що є

| Файл | Що робить |
| --- | --- |
| `agent.py` | Агент (LangChain/LangGraph, ReAct) з інструментами `search_site` і `fetch_page` |
| `evals.py` | Тести в LangSmith: перевірка кодом + LLM-as-a-Judge |
| `app.py` | Вебінтерфейс (Streamlit): запитати агента, побачити відповідь і траєкторію |

## Тести (LangSmith)

Датасет `frex-agent-tests`: 3 питання про ФРЕКС (напр. «Коли був заснований ФРЕКС?») і 2 сторонні («Напиши вірш про осінь»).
На кожному прикладі працюють два оцінювачі:

| Оцінювач | Тип | Що перевіряє |
| --- | --- | --- |
| `tool_check` | Детермінований (код) | Питання про ФРЕКС → агент **обов'язково** викликав `search_site`. Стороннє питання → не викликав інструментів |
| `llm_judge` | LLM-as-a-Judge (`gpt-6.1-sol`) | Інша модель читає питання, траєкторію і відповідь та вирішує, чи агент правильно відреагував: відповів з сайту / відмовив на сторонню тему |

Результати кожного прогону зберігаються в LangSmith як експеримент (Datasets & Experiments → `frex-agent-tests`).

## Як працює

Агент побудований на **LangChain / LangGraph** і працює за циклом **ReAct**:

1. Модель отримує питання і опис інструментів.
2. Модель вирішує, який інструмент викликати.
3. Python виконує інструмент і повертає результат моделі.
4. Кроки 2–3 повторюються, доки не знайдеться відповідь.
5. Модель пише відповідь із посиланням на сторінку-джерело.

### Інструменти

| Інструмент | Що робить |
| --- | --- |
| `search_site(query)` | Пошук сторінок rex.knu.ua через DuckDuckGo (`site:rex.knu.ua`) |
| `fetch_page(url)` | Завантажує сторінку (requests + BeautifulSoup) і повертає заголовок, текст і посилання. Дозволено лише домен rex.knu.ua |

### Стек

- Python 3.12, LangChain, LangGraph
- Модель задається в `.env` (`MODEL=...`): OpenAI, Groq (безкоштовно) або Ollama (локально)
- Трасування: LangSmith

## Запуск (Windows)

1. `setup.bat` — встановлює Python (якщо немає), віртуальне середовище, бібліотеки і створює `.env`.
2. Впиши ключі у `.env` (шаблон — `.env.example`).
3. `ui.bat` — вебінтерфейс у браузері (http://localhost:8501).
4. `tests.bat` — прогнати тести (результати в LangSmith). `run.bat` — одне питання в консолі.

Вручну:

```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
python agent.py "Коли був заснований ФРЕКС?"
streamlit run app.py
python evals.py
```

Вивід: модель, траєкторія (виклики інструментів) і відповідь.
Повний трейс кожного запуску — на smith.langchain.com (якщо `LANGSMITH_TRACING=true`).

## Ключі

| Змінна | Де взяти |
| --- | --- |
| `OPENAI_API_KEY` | https://platform.openai.com/api-keys |
| `GROQ_API_KEY` | https://console.groq.com/keys (безкоштовно) |
| `LANGSMITH_API_KEY` | https://smith.langchain.com → Settings → API Keys (безкоштовно) |

Файл `.env` з ключами не потрапляє в репозиторій (`.gitignore`).
